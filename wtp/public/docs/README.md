# We the People 305: working docs

These are the planning documents for We the People 305, kept in the open. The founder board's assistant (admin.wethepeople305.org) reads every file listed in `index.json` on each question, so what is written here is what it knows. Claude writes these from the vote-informed project; edits by hand are welcome too.

- product.md: what the product is, the organizing model, every layer, the build order
- founder-board.md: the steps to stand the nonprofit up, mirrored from the board
- cycles-coverage.md: what the governance-cycle files cover per body and the known gaps
